# Site page editor header

## Surface

The editor header contains one quiet back action and one page title. The page
slug and home badge are omitted because they repeat the identity already
established by the title and editor route.

## Errors

Loading and error behavior is unchanged; the existing spinner and error banner
remain visible at their current boundaries.

## Tenancy

This is a presentational change over the already tenant-scoped page response.

## Out of scope

Page renaming, slug editing, publishing state, and navigation behavior are
unchanged. The rejected alternative was restyling all three identity fragments,
which would preserve the visual noise instead of removing it.
