# Calm workspace palette

## Surface

The semantic design tokens define a warm, low-contrast workspace: `#F7F5F1`
for page canvas, `#FFFDFC` for cards and panels, `#FFFEFD` for structural
headers, `#E8E3DC` for borders, `#FCE9E3` for soft coral emphasis, and
`#F1EEE8` for muted and hover surfaces.

## Errors

No behavior or error contract changes. Existing status colors and accessible
focus treatments remain distinct from decorative surfaces.

## Tenancy

This is a client-side visual-token change and performs no data access.

## Out of scope

Primary action coral, navigation rail colors, typography, and spacing remain
unchanged. The rejected alternative was overriding individual screens, which
would create palette drift instead of one reusable visual system.
